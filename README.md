# jogo-mario

## Descrição
Jogo estilo plataforma inspirado no universo Mario, desenvolvido em JavaScript.

## Objetivo
Aplicar na prática os conceitos de Git e GitHub (branches, commits, merge) em um projeto de desenvolvimento de software.

## Tecnologias
- HTML
- CSS
- JavaScript
- Vite

## Instalação
cd frontend
npm install

## Execução
npm run dev
